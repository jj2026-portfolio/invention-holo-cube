#Holo Cube
##Holographic-style substrate and system

The Holo Cube is a 3D bead array of LED lights (eg. chandelier) which thusly occupy a x, y and z space within a 3D cube spatial environment. Connected to suitable software triggering each individual LED and with suitable tuned transparency/ opacity any 3D image ie. holographics can be "projected" into the 3D space. Resolution can be increased accordingly based on the array (voxel) size eg. 10x10x10 to 100x100x100.
